# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Rathsted Foundations, please report it privately rather than opening a public issue.

**Contact:** [security@rathsted.ca](mailto:security@rathsted.ca)

**Scope:** This repository, its release artifacts, and container images Rathsted publishes for optional components. Most workloads use **your** images and registries — report issues in those supply chains to their maintainers unless the flaw is in Foundations code or bundled manifests.

**Response:** We will acknowledge your report within 48 hours and provide an initial assessment within 5 business days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | No — upgrade to 2.x ([upgrade guide](docs/upgrade-guide.md#upgrading-from-1x-to-20)) |
| < 1.0   | No        |
